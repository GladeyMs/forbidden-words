# forbidden-words — เกมคำต้องห้าม

เว็บเกมเรียลไทม์: ทุกคนเห็นคำบนหัวของคนอื่น แต่ไม่เห็นคำของตัวเอง ถามตอบกัน (พูดคุยนอกเกม เช่น วอยซ์แชท/นั่งด้วยกัน) เพื่อทายคำของตัวเองให้ได้

## วิธีเล่น
1. คนสร้างห้องจะเป็น **หัวห้อง** ได้รหัสห้อง 4 ตัวและลิงก์แชร์
2. เพื่อนเปิดลิงก์ (หรือใส่รหัส) แล้วใส่ชื่อเข้าห้อง (สูงสุด 12 คน)
3. หัวห้องเลือกเวลาต่อรอบ **3 / 5 / 7 นาที** (ค่าเริ่มต้น 5) แล้วกด **เริ่มเกม** ทุกคนได้คนละคำที่ไม่ซ้ำกัน
4. ถามตอบกันนอกเกม (วอยซ์แชท/นั่งด้วยกัน) เพื่อทายคำของตัวเอง ใครทายถูก **ผู้เล่นคนไหนก็กด "🙋 แจ้งว่าทายถูก" ที่การ์ดของคนนั้นได้** (กดที่การ์ด = คำนี้เป็นของคนนี้ คนอื่นเห็นคำจึงเป็นพยานได้ แจ้งให้ตัวเองก็ได้) แล้ว **หัวห้องกด "✓ ยืนยัน" หรือ "✗ ปฏิเสธ"** คนที่ยืนยันแล้วจึงเห็นคำของตัวเอง ผู้เล่นยืนยันกันเองไม่ได้ และหัวห้องยกเลิกได้ถ้ากดผิด
   - **ถ้าหัวห้องเองเป็นคนทายถูก** หัวห้องยืนยันตัวเองไม่ได้ ต้องให้ผู้เล่นคนอื่นโหวต "✓ ยืนยัน" ให้ **เกินครึ่งของผู้เล่นคนอื่น** (เช่น 2 คนต้องครบ 2, 3 คนต้อง 2, ห้องที่มี 2 คนรวมหัวห้อง คนเดียวตัดสิน) การยกเลิกคะแนนของหัวห้องก็ใช้เสียงข้างมากเช่นกัน
5. **หมดเวลา** (หรือหัวห้องกดจบรอบ) เข้า **ช่วงทายสุดท้าย**: คนที่ยังไม่ถูกยืนยันพิมพ์ทายคำของตัวเอง ทุกคนเห็นคำทาย ใครเห็นว่าถูกก็แจ้ง หัวห้องยืนยัน (ของหัวห้องใช้โหวต) แล้วกด **เฉลยทุกคน**
   (เฉลยอัตโนมัติถ้าทุกคนถูกตัดสินว่าทายถูกครบ) จากนั้นหัวห้องกด **เล่นรอบใหม่**

หัวห้องยังเชิญคนออก และใส่ชุดคำของตัวเองได้ในล็อบบี้ เวลานับที่เซิร์ฟเวอร์ ไม่ใช่นาฬิกาเครื่องผู้เล่น

## คะแนน
- ทายถูกก่อนหมดเวลา: ได้ตามลำดับที่ยืนยัน คนแรกได้เท่าจำนวนผู้เล่นตอนเริ่มรอบ คนถัดไปลดทีละ 1 (ต่ำสุด 1)
- ทายถูกในช่วงทายสุดท้าย: ได้ 1 คะแนนคงที่ ไม่ถูกยืนยัน: 0
- คะแนนสะสมข้ามรอบในห้องเดียวกัน มีตารางคะแนนเรียงอันดับ หัวห้องกด **รีเซ็ตคะแนน** ได้ในล็อบบี้
- คะแนนคำนวณที่เซิร์ฟเวอร์ใหม่ทุกครั้งจากลำดับที่ยืนยัน (กดยกเลิกแล้วอันดับปรับเอง) และถ้าหัวห้องยกเลิกรอบกลางคัน คะแนนของรอบนั้นจะถูกคืน
- หัวห้องยืนยันคนอื่นได้แม้ไม่มีใครแจ้ง (ทางลัด) ถ้าหัวห้องกลางรอบออกจากห้อง ผู้ตัดสินเปลี่ยนเป็นคนใหม่และคำแจ้ง/โหวตที่ค้างจะถูกล้าง
- ข้อจำกัด: ผู้ตัดสินยังเป็นคนในห้อง ถ้าทุกคนสมรู้ร่วมคิดก็โกงได้ ระบบกันได้แค่การโกงโดยคนเดียว (ผู้เล่นยืนยันตัวเองไม่ได้ หัวห้องยืนยันตัวเองไม่ได้)

## ความปลอดภัยของกติกา
เซิร์ฟเวอร์เป็นคนตัดสินว่าใครเห็นอะไร: คำของผู้เล่นจะ **ไม่ถูกส่ง** ไปยังเครื่องของเจ้าของคำ
จนกว่าเขาจะกดทายถูกหรือหัวห้องเฉลย (ไม่ได้ซ่อนด้วย CSS) และมีเทสต์ตรวจเรื่องนี้ใน `test/`

## รันในเครื่อง
```bash
npm install
npm test
npm start   # http://localhost:3000
```

## Deploy บน Railway
- ใช้ Node.js 24.22.1 (ล็อกไว้ใน `engines` ของ package.json, Railway ตรวจเจออัตโนมัติ) คำสั่งเริ่ม `npm start` อ่านพอร์ตจาก `PORT`
- Health check: `/healthz`
- ไม่ต้องตั้งตัวแปรเพิ่ม ไม่มีฐานข้อมูล

## ข้อจำกัดที่ควรรู้
- ห้องเก็บอยู่ในหน่วยความจำของ process เดียว: restart/redeploy แล้วห้องหายหมด และรัน replica เกิน 1 ตัวไม่ได้
- ห้องที่ไม่มีใครออนไลน์ 10 นาทีจะถูกลบ
- ไม่มีบัญชีผู้ใช้ การกลับเข้าห้องหลังรีเฟรชใช้ token ใน localStorage ของเบราว์เซอร์
