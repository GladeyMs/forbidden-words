# forbidden-words — เกมคำต้องห้าม

เว็บเกมเรียลไทม์: ทุกคนเห็นคำบนหัวของคนอื่น แต่ไม่เห็นคำของตัวเอง ถามตอบกัน (พูดคุยนอกเกม เช่น วอยซ์แชท/นั่งด้วยกัน) เพื่อทายคำของตัวเองให้ได้

## วิธีเล่น
1. คนสร้างห้องจะเป็น **หัวห้อง** ได้รหัสห้อง 4 ตัวและลิงก์แชร์
2. เพื่อนเปิดลิงก์ (หรือใส่รหัส) แล้วใส่ชื่อเข้าห้อง (สูงสุด 12 คน)
3. หัวห้องกด **เริ่มเกม** ทุกคนจะได้คนละคำที่ไม่ซ้ำกัน
4. ถามคำถามที่ตอบแค่ใช่/ไม่ใช่ เมื่อทายถูกกด **ฉันทายถูกแล้ว** เพื่อเปิดคำตัวเอง
5. หัวห้องกด **เฉลยทุกคน** หรือเฉลยอัตโนมัติเมื่อทุกคนทายถูก แล้วกด **เล่นรอบใหม่**

หัวห้องยังเชิญคนออก และใส่ชุดคำของตัวเองได้ในล็อบบี้

## ความปลอดภัยของกติกา
เซิร์ฟเวอร์เป็นคนตัดสินว่าใครเห็นอะไร: คำของผู้เล่นจะ **ไม่ถูกส่ง** ไปยังเครื่องของเจ้าของคำ
จนกว่าเขาจะกดทายถูกหรือหัวห้องเฉลย (ไม่ได้ซ่อนด้วย CSS) และมีเทสต์ตรวจเรื่องนี้ใน `test/`

## รันในเครื่อง
```bash
npm install
npm test
npm start   # http://localhost:3000
```

## Deploy บน Railway
- ใช้ Node.js 24.22.1 (ล็อกไว้ใน `engines` ของ package.json, Railway ตรวจเจออัตโนมัติ) คำสั่งเริ่ม `npm start` อ่านพอร์ตจาก `PORT`
- Health check: `/healthz`
- ไม่ต้องตั้งตัวแปรเพิ่ม ไม่มีฐานข้อมูล

## ข้อจำกัดที่ควรรู้
- ห้องเก็บอยู่ในหน่วยความจำของ process เดียว: restart/redeploy แล้วห้องหายหมด และรัน replica เกิน 1 ตัวไม่ได้
- ห้องที่ไม่มีใครออนไลน์ 10 นาทีจะถูกลบ
- ไม่มีบัญชีผู้ใช้ การกลับเข้าห้องหลังรีเฟรชใช้ token ใน localStorage ของเบราว์เซอร์
